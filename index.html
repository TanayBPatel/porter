Chat Porter

Export the chat.
Keep the context.

A Chrome extension that turns ChatGPT, Claude, Gemini, DeepSeek and Grok conversations into clean Markdown, PDF, Word, HTML or JSON — or a compact context pack you can paste into another AI.

Chrome Web Store Listing coming soon · replace this link after approval
100% on-device. No accounts, no analytics, no servers. Your conversations never leave your browser.

What it does

Context mode

Compact by default. Older turns are condensed, the latest exchange stays in detail, and you can copy the result into any chat.

Review & export

See every message, tick exactly what you want, then download Markdown, PDF, Word, HTML, JSON or plain text.

Attachments

PDFs, documents, spreadsheets, presentations, archives and code files are detected and included as typed links.

Thinking blocks

Keep or remove the assistant’s reasoning with one checkbox. Nothing is forced into the export.

Supported sites

  • ChatGPT — chatgpt.com and chat.openai.com
  • Claude — claude.ai
  • Gemini — gemini.google.com
  • DeepSeek — chat.deepseek.com
  • Grok — grok.com and x.com/i/grok

Privacy

Chat Porter processes everything in your browser. It does not collect or transmit conversation content and contains no remote code. Read the privacy policy.
